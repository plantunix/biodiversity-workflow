# Taxonomy Metadata Fetcher

Python Scripts for <u>sequence </u> and <u>taxonomy metadata </u> retrieval from available public databases.


## Structure

#### This repo contains 2 pipelines:

* Sequence data retrieval:
  * Includes `seqmain.py` and `seqtools/`
  * To be run with `seqmain.py`
 
  * ### How to run:
    * Run seqmain.py
    * Input species name file
    * Input gene marker to search for
    * Input file format (fasta for simple annotation, gbk for complex metadata)
    * Input output csv file (.csv) 

 
* Taxonomy and trait metadata retrieval:   (In progress)
  * Includes `main.py`, `utils/`, `tools/` and everything else.
  * To be run with `main.py`
